## 2. 首页规格（图1 = A 版，图2 = B 版）

结构自上而下：状态栏 → 品牌头 → 卡包主视觉区 → 黑色胶囊 CTA → 今日小事面板 → 今日拼图面板 →（B 版多一条水彩横幅）→ 底部 Tab。

- 品牌头：左侧椭圆手绘圈 Logo「LIFE PACK ✦」（斜置约 -4°），其下日期「9月20日 星期日」；
  右侧铃铛带红点。开包页无品牌头（见第 4 节）。
- 卡包主视觉：卡包图用 `mobile/assets/packs/pack_sealed.png`（含涂鸦与中文标语的原图）。
  A 版：居中，宽 ≈196pt（@375），左便签涂鸦「每一次抽卡都是一次新的生活」，
  右上斜排手写引语「今天也没啥事，要不要抽一张？」(-5°)，右侧竖排「Random Life Event」涂鸦。
  B 版：卡包靠右上，宽 ≈158pt；引语在左侧。
- CTA：黑色胶囊按钮「拆开看看 →」，手写体，左右各一枚 ✦，位于卡包下方独立一行，点击进开包页。
- 今日小事面板：白色面板，右上回形针装饰；标题行 = 太阳图标 +「今日小事」+ 计数胶囊「2/4」，
  右侧手写注脚「小小的完成，就是大大的生活」。
  任务行（B 版结构）：勾选框（完成 = 黑底白 ✓）→ 圆形 pastel 图标 → 标题 + 灰色副标题 →
  右侧「🧩 +1 拼图碎片」（仅完成行显示，A 版同）+ 紫色 ✓（完成）/ 浅色空心圆（未完成）。
  四行内容以设计图为准：好好刷牙（清新的开始，给今天加点分。）/ 喝一杯水（身体的第一杯水很重要。）/
  看 1 页书（今天只看一页就够了）/ 出门晒 5 分钟（不想出门也没关系）。面板右下角猫涂鸦。
- 今日拼图面板：标题行 = 拼图图标 +「今日拼图」+「3/5」，右侧手写注脚「拼齐五片，解锁隐藏卡片！」。
  5 块拼图横排：已得 = 虹彩箔纹理，空位 = 浅色描边；行末 ›。
- B 版底部横幅：水彩底条，左手写「收集生活的碎片，拼成更特别的自己 ✦」，右猫涂鸦。
- 底部 Tab：首页（激活，图标填充 + 下划线）/ 任务 / 卡册 / 我的，与现有 BottomTabBar 对齐即可。

## 4. 开包页规格（图3 = C 版，`mobile/src/app/pack/opening.tsx`）

设计 C 是进入撕包交互**之前**的全屏氛围首屏（不是替换现有撕包流程）：

- 纯黑底（#030304），棱镜光束自顶部斜射、地面有卡包的镜面反射（倒影渐隐），细椭圆轨道环绕卡包，点缀 ✦。
- 左上仅日期「9月20日 星期日」（白字，字距放大），**无品牌头、无铃铛**。
- 卡包大尺寸居中斜置（宽 ≈252pt，-6°），轻微悬浮动效可沿用现有 reanimated 浮动。
- 左下手写两行（白字，带手绘下划线）：「今天也没啥事。/ 那就抽一张吧。」
- 右下吉祥物猫涂鸦 + 「LIFE PACK」落款。
- 交互：点击任意处或上滑 → 进入现有 ThreePackStage 撕包流程（576 行现实现不动）。
