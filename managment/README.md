# LIFE PACK 卡片与卡包资产制作台 (Card & Digital Pack Asset Studio)

> 基于 `LIFE_PACK.md` 规范全面升级的官方数字卡片与卡包视觉资产制作、组织、维护与留档管理系统。  
> 结合底层 WebGL2 过程光学引擎、2.5D 分层视差渲染、卡片视觉模板模组系统与 Express 后端持久化存储。

---

## 📌 系统定位与范围说明

本项目专为 **官方内容团队与设计师** 打造的 **数字资产生产与留档工作台**：
- ✅ **包含**：卡片内容与任务规则编辑、主体与背景图层装配、卡片模板与等级模组调色配置、全息光学参数配置、属性标签库与 1~5 星星级评价、数字卡包组装与整套资产 ZIP 打包导出。
- ❌ **严格排除**：抽卡概率/卡池玩法、用户背包与实例账户、碎片解谜拼图逻辑、支付结算与社交分享系统。

---

## 🌟 四大核心功能模块

### 1. 制作台首页 (Studio Dashboard)
- **核心资产概览**：统计全库卡片总数、卡包总数以及配置就绪的等级视觉模组。
- **阶段流转指标**：统计草稿 (DRAFT)、待审核 (READY_FOR_REVIEW) 与待导出 (READY_FOR_EXPORT) 资产。
- **快捷入口**：一键新建卡片、快速前往数字卡包库或卡片模板库。

### 2. 卡片资产库与制作台 (Card Library & Studio)
- **卡片资产列表检索**：支持按业务编号 (如 `LP-0027`)、卡片名称、任务文案即时搜索；支持按系列 (Series)、主分类 (Category) 与制作状态过滤；提供一键克隆副本、导出卡片 JSON、安全删除等功能。
- **专注内容生产的 3D 制作台**：
  - **等级模组下拉绑定 (Select)**：直接下拉选择卡片模板库中已配置好的模组（如：普通·冷钛银灰、高级·皇家香槟金、稀有·冰川珍珠蓝或自创模组），卡片自动继承全部边框调色与光学参数。
  - **属性标签库与 1~5 星评价**：通过下拉列表从全局标签库中添加胶囊标签，支持点击直接调整 1~5 颗星评级（如：`荒谬 ★★★★★`、`社交 ★★☆☆☆`），并在 Canvas 高清层实时绘制出微缩星级图标。
  - **极简图层装配**：作者仅需聚焦上传 **核心透明主体图片 (`subject.png`)** 与 **背景底图 (`background.png`)**，自动进行 Alpha 透明通道检验，无需在卡片制作台反复调节繁琐的底层着色器滑块。
  - **封印态与解封态机制**：支持覆盖低饱和毛玻璃、纯平无 2.5D 畸变、中央金色封印罗盘 (LIFE SEAL) 一键切换。
  - **2D 纯平静态合图与缩略图截取**：支持生成原画无畸变静态大图并自动保存正面 3D 视角缩略图。

### 3. 数字卡包工坊 (Digital Pack Studio)
- **三维卡包切片组装**：卡包正面立绘 (`pack_front`)、侧边厚度材质、背面说明、撕开口纹理与专属光泽度。
- **卡包卡池编组**：勾选已就绪卡片入包，支持设定卡包封面推荐卡。
- **一键打包导出 ZIP**：导出符合游戏客户端/分发平台规范的标准压缩包，包含完整的 `pack_manifest.json`、包装贴图与所有入包卡片的图层切片。

### 4. 卡片模板库 (Card Template Studio)
- **等级体系与模组中心**：统一管理普通、高级、稀有以及自定义新建的卡片等级模组（如：SP 典藏、神话、限定极光等）。
- **边框呈现双模态**：
  - **模式 A (程序化矢量边框)**：未上传外部边框贴图时，提供**画图式交互色盘与拾色器**（预设色板、HEX 取色器、辅色与流光辉光基调），程序化自研生成契合的边框。
  - **模式 B (自定义边框切片)**：上传透明 PNG 边框贴图后，自动切换为贴图渲染，支持表层覆盖 (`OVERLAY_FRONT`) 或前后分层穿透 (`SPLIT_BACK_FRONT`)。
- **全息光学蒙版与发光光效配置**：
  - 光学蒙版：全息虹彩蒙版、封印毛玻璃蒙版、丁达尔阳光蒙版、棱镜色散、星云流沙、金属蚀刻。
  - 结构线发光模式：微弱阳光、暖金丁达尔、全息虹彩。
  - 实时 3D 视口：在模板库调色或调整光学滑块时，中间 3D 视口实时响应所见即所得。

## 🚀 启动与使用指南

### 1. 启动本地开发环境
```bash
npm run dev
```
启动后在浏览器打开：`http://localhost:5173/`

### 2. 生产打包构建
```bash
npm run build
```
执行 TypeScript 类型校验并生成优化后的静态资源包至 `dist/` 目录。

## 📡 REST API 端点说明

| 端点路径 | HTTP 方法 | 功能说明 |
| :--- | :--- | :--- |
| `/api/health` | GET | 服务健康检查 |
| `/api/meta` | GET | 获取内容系列、主分类与 IP 角色字典 |
| `/api/cards` | GET, POST | 查询卡片列表（支持搜索/过滤）或新建卡片 |
| `/api/cards/:id` | GET, PUT, DELETE | 获取、更新或删除指定卡片 |
| `/api/cards/:id/clone` | POST | 快速克隆卡片并生成唯一新编号 |
| `/api/packs` | GET, POST | 查询卡包列表或创建新数字卡包 |
| `/api/packs/:id` | GET, PUT, DELETE | 获取、更新或删除数字卡包 |
| `/api/templates` | GET, POST | 查询卡片模板与模组列表，或创建新模组 |
| `/api/templates/:id` | GET, PUT, DELETE | 获取、更新或删除模组（具备卡片引用保护校验） |
| `/api/tags` | GET, POST | 获取属性标签库列表或新增标签 |
| `/api/tags/:id` | DELETE | 删除指定属性标签 |
| `/api/assets/upload` | POST | 上传切片素材（自动二进制解析宽高与 Alpha 通道） |
